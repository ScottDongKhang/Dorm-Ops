# Dorm Ops

Residential life management system for boarding schools. Streamlines event coordination, announcements, and student engagement.

## Features
- 📅 Event signups with waitlist auto-promotion
- 🤖 AI-powered event creation (paste text, auto-fills form)
- 📢 Announcements with read tracking
- 📊 Admin analytics dashboard
- 📱 Mobile-friendly, works offline

## Tech Stack
Single-file HTML/CSS/JavaScript app with localStorage persistence. No backend required.

## Quick Start
1. Download `index.html`
2. Open in browser
3. Login: `student1@villanovaprep.org` / `demo123`

Works on any static host (GitHub Pages, Netlify, Vercel). Just upload the HTML file.
